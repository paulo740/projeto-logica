# projeto-logica
projeto de calcular impostos

##integrantes
paulo cesar n29

Este programa calcula o preço final de um produto após aplicar um desconto informado pelo usuário. Se o valor após o desconto ultrapassar um limite definido, um imposto adicional é aplicado sobre o valor com desconto. O programa mostra o preço original, preço com desconto, imposto (se aplicado) e o preço final.
